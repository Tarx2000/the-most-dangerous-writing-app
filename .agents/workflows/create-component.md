# Create a Component Workflow

When asked to create a new UI component in this project, follow these instructions:

1. Always use `StyleSheet.create` for styling.
2. Keep the component in the root `components/` directory (create it if it doesn't exist).
3. Use TypeScript functional components `React.FC`.
4. Stick to the app's core aesthetic: Danger Red (`#ff4d4d`), Dark Background (`#000000` or `#111111`), and Light Text (`#F3F4F6`).

// turbo
5. Let the user know the component is ready!
