# Vercel React Best Practices — React Native Edition

Condensed performance guide for React Native based on the Vercel Engineering React/Next.js guide. This edition removes all web-specific rules (SSR, RSC, Next.js API routes, HTML script tags, hydration) and keeps only universal React + React Native relevant patterns.

## How to Use

Reference the compact rule index in `AGENTS.md`. For detailed examples of a specific rule, read the corresponding file under `rules/`.
