# Plan: Floating "Scroll to Top" Button in Feed

## Goal
Add a floating button to the FeedScreen that appears when the user has scrolled down a few entries, allowing them to jump back to the top of the feed with a beautiful fade in/out animation.

## Current Architecture Context
- **FeedScreen** (`src/screens/FeedScreen.tsx`) renders an `AnimatedFlashList` inside a `GestureDetector`.
- Scroll position is already tracked via `listScrollY` SharedValue (passed from `useHomeGestures` or local fallback).
- The app uses **Reanimated v4** with SharedValues for all animations.
- **Theme**: AMOLED dark (`#000` background), glassmorphism tokens (`glassBackground`, `glassBorder`, `glassHighlight`), accent color is `primaryAction` (`#FF2A2A`).
- **UI primitives**: `AnimatedScaleButton` exists in `src/components/ui/AnimatedScaleButton.tsx` for touch-responsive buttons with spring animations.
- **Icons**: `MaterialCommunityIcons` is used throughout.
- **Animation springs**: `theme.animation.springSnappy`, `springGentle`, `springLight` are available.

## Proposed Implementation

### 1. Scroll Threshold Detection
- Use the existing `listScrollY` SharedValue in `FeedScreenInner`.
- Define a threshold (e.g., `SHOW_SCROLL_TOP_THRESHOLD = 200` pixels).
- Use `useAnimatedReaction` to watch `listScrollY.value` and toggle a `showButton` SharedValue (`0` or `1`).
- Show button when `listScrollY.value > SHOW_SCROLL_TOP_THRESHOLD`.
- Hide button when `listScrollY.value <= SHOW_SCROLL_TOP_THRESHOLD`.
- This runs entirely on the UI thread (no React state for visibility), keeping performance optimal.

### 2. Button Component & Placement
- Add an absolutely positioned `Animated.View` floating **above** the `AnimatedFlashList` but **inside** the same container (`View style={styles.container}`).
- Position: `position: 'absolute'`, `bottom: 24`, `right: 20` (or bottom-center), with `zIndex` high enough to sit above list content.
- Use `AnimatedScaleButton` (or a custom Pressable wrapper) for the tap target so it inherits the app's tactile spring scaling on press.
- Inside: a `MaterialCommunityIcons` arrow-up icon.
- Size: ~48×48 dp (compact but tappable).
- Style: glassmorphism pill/circle matching the app's nav/filter buttons (`glassBackground`, `glassBorder`, `1px border`).

### 3. Fade Animation
- Drive opacity via a `useAnimatedStyle` that reads a `buttonOpacity` SharedValue.
- `buttonOpacity.value = withTiming(showButton.value, { duration: 250 })`.
- Add a subtle `translateY` shift (`0 → 10px`) during the fade for a premium feel.
- Wrap the animated view in `React.memo` to prevent unnecessary re-renders.

### 4. Scroll-to-Top Action
- On press, call `listRef.current?.scrollToOffset({ offset: 0, animated: true })`.
- The existing `listRef` is already typed as `FlashListRef<FeedItem>`.

### 5. Gesture Interop
- The feed already has a `feedPanGesture` for closing the feed. The floating button sits **outside** the `GestureDetector` wrapping the list, or we use `hitSlop` and `pointerEvents` so the button receives taps independently without interfering with the pan gesture.
- Since the button is an `Animated.View` sibling of the `GestureDetector`, it naturally receives touches first when overlaid correctly.

## Files to Modify
- `src/screens/FeedScreen.tsx` — add threshold logic, button JSX, and styles.

## Files to Potentially Create
- None (implementation is small enough to inline in FeedScreen; if it grows, extract to `src/components/features/feed/ScrollToTopButton.tsx`).

## Decisions (User-Confirmed)
- **Position**: Bottom-right corner, icon-only.
- **Scroll threshold**: ~300 pixels (`SCROLL_TOP_SHOW_THRESHOLD = 300`).
- **Icon**: `arrow-up` (MaterialCommunityIcons).
- **Haptics**: No vibration on tap.
- **Visual style**: Circular glassmorphism button (no text). Uses `theme.colors.glassBackground`, `theme.colors.glassBorder`, with a subtle `glassHighlight` active state or border glow.
