# Plan: Stable End-to-End AI Test Suite

## Goal
Create a deterministic, deeply-instrumented test suite that validates the entire AI processing lifecycle — from a dummy journal entry through `AiQueueManager` → `aiService` → live Ollama Cloud API — and back to the updated note. The suite must be easy to debug (step-level tracing) and stable (fallback to fully mocked tests when the API is unreachable).

## Why Two Files?
Hitting a live API is inherently non-deterministic (network latency, model variance, outages). To give the user the "best of both worlds" they asked for, we deliver:
1. **Mocked suite** (`aiEndToEnd.mock.test.ts`): 100% deterministic, fast, tests every state transition, retry path, cancellation, batch ordering, orphan recovery, and pre-flight validation. This is the primary regression guard.
2. **Live smoke suite** (`aiEndToEnd.live.test.ts`): Hits the real Ollama Cloud API with the hardcoded key, measures latency, gates itself via `pingServer()`, and performs a real end-to-end queue lifecycle. Skips gracefully when the server is down.

## Files to Create

### 1. `src/lib/__tests__/aiEndToEnd.mock.test.ts` — Deterministic Full Lifecycle

#### Test Tracer Utility
Create a reusable `AiTestTracer` class inside the test file that records every step with a high-resolution timestamp (`performance.now()` where available, otherwise `Date.now()`). On assertion failure it prints a human-readable timeline with deltas between steps.

Steps traced:
- `test_start`
- `note_created`
- `queue_initialized`
- `note_enqueued`
- `job_status:que → processing`
- `ai_request_start`
- `ai_request_end`
- `job_status:processing → done/failed`
- `note_updated`
- `queue_empty`
- `test_complete`

#### Test Cases
1. **full lifecycle: note → enqueue → process → updated note**
   - Dummy `SavedNote` with realistic 250-word entry.
   - Initialize `aiQueue` with mocked `getAiConfig`, `getNoteById`, `updateNote`, `getAllNotes`.
   - Mock `processNote` to resolve `{ title: 'Mocked Title', summary: ['Point 1', 'Point 2'], failed: false }`.
   - Wait for `AI_QUEUE_EVENT` until `pendingCount === 0`.
   - Assert `updateNote` called with exactly: `{ aiTitle: 'Mocked Title', aiSummary: ['Point 1', 'Point 2'], aiModelUsed: 'test-model' }`.
   - Assert job status === `'done'`, `retryCount === 0`.
   - Assert tracer timeline has all steps in order, each with a positive duration.
   - Assert AI logger called with `enqueue`, `start`, `success`.

2. **retry path: transient failure on first two attempts**
   - Mock `processNote` to reject twice with `"Network request failed"`, then succeed.
   - Assert `retryCount` ends at `2`.
   - Assert job ends as `'done'`.
   - Assert AI logger has `fail`, `retry`, `success`.
   - Assert tracer shows `ai_request_start` → `ai_request_end` three times.

3. **cancellation mid-flight**
   - Enqueue note. Call `aiQueue.cancelJob(jobId)` immediately after `status` becomes `'processing'`.
   - Assert job ends as `'failed'` with `error === 'Cancelled by user'`.
   - Assert `updateNote` was **not** called after cancellation.
   - Assert no orphan left in `'processing'`.

4. **batch enqueue respects category ordering and newest-first**
   - Seed mock notes: 1 journal (oldest), 1 circle (middle), 1 checkin (newest), plus 1 journal (newest).
   - Call `enqueueBatch(false)`.
   - Assert 4 jobs enqueued in order: journal newest, journal oldest, circle middle, checkin newest.
   - Assert batch progress `{ current, total }` is emitted correctly.

5. **pre-flight validation fails fast with missing API key**
   - Initialize with `apiKey: ''`.
   - Enqueue note.
   - Allow microtask queue to drain (no `process.nextTick` needed in Jest, just `await flushPromises()`).
   - Assert job status `'failed'` with error containing `"API key"`.
   - Assert `processNote` mock was never called.

6. **orphan recovery on init**
   - Mock `AsyncStorage.getItem(AI_STORAGE_KEYS.QUEUE)` to return a JSON array with one job stuck in `'processing'`.
   - Initialize `aiQueue`.
   - Assert the job is reset to `status: 'queued'`, `retryCount: 0`, `error: undefined`.
   - Assert AI logger contains `orphan_recovery`.

#### Mocking Strategy
- Use `jest.mock('@/lib/aiService', ...)` with `jest.fn()` implementations that can be overridden per-test.
- Use `jest.mock('@/lib/aiLogger', ...)` to capture log entries in a test-scoped array.
- Use `jest.mock('@react-native-async-storage/async-storage', ...)` consistent with existing `aiQueue.test.ts`.
- Reset `aiQueue` via `shutdown()` + `initialize()` in `beforeEach`.
- Flush promises helper:
  ```typescript
  const flushPromises = () => new Promise(r => setTimeout(r, 0));
  ```
  (needed because some queue calls are `setTimeout` based).

### 2. `src/lib/__tests__/aiEndToEnd.live.test.ts` — Live API Smoke Test

#### Gating Behavior
`beforeAll` calls `pingServer()` with the default config (hardcoded key from `ai.ts`). If `online === false`, call `console.warn('[LIVE TEST] Ollama Cloud unreachable — skipping live suite')` and invoke `jest.skip()` or mark all tests as skipped.

#### Dummy Entry
A realistic 280-word journal entry covering work stress, a social interaction, and personal reflection:
> "Today was exhausting but illuminating. I spent the morning wrestling with a bug in the authentication flow that kept rejecting valid tokens..."
*(full text will be included in the file).*

#### Test Cases
1. **ping server**
   - `pingServer()` → assert `online: true`, log latency.

2. **generateTitle live**
   - `generateTitle(dummyEntry)` → assert non-empty string, length < 100 chars, no surrounding quotes.
   - Log latency. Assert < 30s.

3. **generateSummary live**
   - `generateSummary(dummyEntry)` → assert array, length between 2 and 5, each bullet non-empty.
   - Log latency.

4. **checkGrammar live**
   - `checkGrammar(dummyEntryWithTypos)` → assert array, each item has `original`, `suggestion`, `explanation` strings.
   - Log latency.

5. **processNote live**
   - `processNote(dummyEntry)` → assert `failed: false`, `title` defined, `summary` non-empty array.
   - Log latency.

6. **full queue lifecycle live**
   - Initialize `aiQueue` with real `getAiConfig`, `getNoteById`, `updateNote`, `getAllNotes`.
   - Enqueue dummy note.
   - Poll `getState()` (or listen to `AI_QUEUE_EVENT`) until `pendingCount === 0` and `isProcessing === false`.
   - Timeout: 120s (`jest.setTimeout(120000)`).
   - Assert `updateNote` called with `aiTitle` and `aiSummary` populated by the real model.
   - Print tracer summary of total end-to-end time.

#### Mocking Strategy
- **NO mock** for `@/lib/aiService` — use real functions.
- Mock only `react-native` native modules (`DeviceEventEmitter`, `AppState`) and `AsyncStorage`.
- Mock `@/lib/aiLogger` to capture entries for post-test inspection.

## Implementation Steps

2. Write `aiEndToEnd.mock.test.ts` — deterministic mocked suite.
3. Write `aiEndToEnd.live.test.ts` — gated live smoke suite.
4. Run `npm test -- aiEndToEnd` and fix any flakiness.
5. Ensure TypeScript strict mode passes (`npm run typecheck`).

## Validation Criteria
- Deterministic tests run and pass in < 5s total.
- Live tests are skipped automatically when the API is down (no false failures).
- Every test failure prints a step-level tracer timeline.
- No `any` types introduced.
- All existing tests continue to pass.
