## Remaining Critical Issues (Ranked)

### 🔴 Critical (1)

**1. Accessibility Crisis — AnimatedScaleButton strips all a11y props**
- **Scope**: `src/components/ui/AnimatedScaleButton.tsx`, cascading to 30+ usage sites across every screen
- **Issue**: The component wraps `Pressable` but does NOT accept or forward `accessibilityLabel`, `accessibilityRole`, `accessibilityHint`, or `accessibilityState`. The entire app is effectively invisible to screen readers.
- **Fix**: Extend `AnimatedScaleButtonProps` to accept a11y props and spread them onto the inner `Pressable`.
- **Status**: ⏭️ Skipped per user request — private project, screen-reader support not required.

### 🟠 High (3) — ALL FIXED ✅

**2. Race Conditions — Async setState without unmount guards**
- **Files**: `src/screens/PostWritingScreen.tsx:112-131`, `src/screens/VlogRecordingScreen.tsx:178-350`, `src/lib/hooks/useStorage.tsx:337-353`
- **Fix**: Added `const isMountedRef = useRef(true)` and guarded all post-await setters with `if (!isMountedRef.current) return;` before state updates.

**3. Magic Numbers — Scattered hardcoded thresholds/timeouts**
- **Files**: `src/screens/HomeScreen.tsx:134`, `src/screens/StartScreen.tsx:214-215`, `src/screens/VlogRecordingScreen.tsx:111,151`, `src/components/ui/PinPadModal.tsx:114`
- **Fix**: Centralized into `CONFIG` in `src/config/index.ts` (`CHECKIN_URGENT_DAYS`, `CHECKIN_URGENT_MS`, `DEV_MODE_LONG_PRESS_MS`, `DEV_MODE_TOAST_DURATION_MS`, `PIN_DOT_DELAY_MS`, `PERMISSION_GRANTED_DELAY_MS`, `COUNTDOWN_INTERVAL_MS`).

**4. `console.log` / `console.warn` in Production Code**
- **Files**: `src/lib/videoCompressor.ts`, `src/lib/hooks/useStorage.tsx`, `src/lib/aiLogger.ts`
- **Fix**: Replaced bare `console.log/warn` with structured `logger()` calls or gated behind `if (__DEV__)` where appropriate. Already completed in prior round.

### 🟡 Medium (3) — ALL FIXED ✅

**5. SharedValue Read During Render (`PinPadModal`)**
- **File**: `src/components/ui/PinPadModal.tsx`
- **Fix**: Removed `&& opacitySV.value === 0` from the render-time conditional, relying on `isVisible` state alone.

**6. Dead Code — Unused exports**
- **Files**: `src/lib/db.ts`, `src/lib/repositories/notesRepository.ts`, `src/lib/storageManager.ts`
- **Fix**: Removed unused exports (`resetDbInstance`, `noteToStreakHistory`, `DEFAULT_VLOG_STORAGE_CAP_BYTES`, `MIN_FREE_SPACE_BYTES`). Already completed in prior round.

**7. Persistent `any` Types in UI Components**
- **Files**: `src/components/ui/LiquidMorphIcon.tsx`, `src/components/features/feed/FeedVideoCard.tsx`
- **Fix**: Replaced `any` with proper types (`StyleProp<ViewStyle>`, `VideoPlayer`). Already completed in prior round.

### 🟢 Low (3) — ALL FIXED ✅

**8. Error Boundary Gaps in Heavy Modals**
- **Files**: `src/screens/LibraryScreen.tsx` (`NoteViewerModal`, `ConfirmDialog` × 2, `PersonProfileModal`)
- **Fix**: Wrapped each modal/dialog in `<ErrorBoundary>` from `@/components/ui/ErrorBoundary`.

**9. ESLint Config Outdated (Blocks linting)**
- **File**: `.eslintrc.js` → `eslint.config.js`
- **Fix**: Migrated to ESLint flat config (`eslint.config.js`), installed `typescript-eslint`, `@eslint/js`, `eslint-plugin-react-hooks`, `globals`. Updated `lint` script. Removed legacy `.eslintrc.js`.

**10. Gradient Hardcoded `rgba` in `LibraryScreen` (minor)**
- **File**: `src/screens/LibraryScreen.tsx:243-268`
- **Fix**: Replaced `rgba(0,0,0, ...)` gradient stops with `theme.colors.overlayDark`, `theme.colors.overlaySubtle`, `transparent`, and `theme.colors.background` tokens. Added `overlayStrong` and `overlaySubtle` to `theme.ts`.
